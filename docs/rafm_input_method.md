# RAFM-Ang input parameterization study

This is an empirical input ablation of the existing angular transport objective. A uses the original ambient input. B uses unit direction and standardized log-radius. C has exactly B's modules and parameter count but its radius-condition argument is identically zero. Class conditioning remains unchanged. No conclusion about improvement is implied by this implementation.

The three-hidden-layer width-128 vector MLP receives one additional scalar input in B/C: 128 additional parameters. The original input-coordinate and time weights, biases and all subsequent layers retain the same seeded initialization as A. The audio U-Net receives a 1→16→256 SiLU radius embedding added to its existing time embedding: 4,384 additional parameters. The image SiT receives 1→16→384 in the corresponding pathway: 6,560 additional parameters. Both downstream backbones retain their original class and time modules, width and depth. Extra-module initialization preserves the original post-construction RNG state; B/C initialize identically. Their constant-input versus sample-dependent use is their only architectural difference.

Radius statistics are population mean and standard deviation of `log(max(R,1e-8))`, accumulated in float64 over generator-training values only. The divisor is at least 1e-8. The saved statistics include training-value and training-index hashes and counts of zero/sub-floor radii. Exact zero input maps to zero direction. Positive directions are computed by dividing first by the largest absolute coordinate and then by the resulting norm; this avoids underflow and avoids leaking sub-epsilon input amplitude into C through a clamped denominator. There is no whitening or additional global input scaling.

The original matched-radius source/time RNG order, spherical path, target `u_t / max(||x_t||,1e-8)`, and mean-over-batch sum-over-coordinates angular MSE are retained. The original ambient RK4 update, tangent projection, radius multiplier and numerical guards are reused. B conditions on the radius of the current solver state; C passes zero. No extra sphere projection or state renormalization is introduced. Each run records initial/final radius drift, actual network calls, conditioning overhead, training/sampling time, and peak memory.

The new downstream runs use the repository's shared seed helper, which explicitly sets deterministic cuDNN/MIOpen behavior and disables benchmark autotuning. Historical audio/image seed functions did not explicitly set that flag. This execution difference is recorded, applies equally to new A/B/C and t-Flow, and precludes treating historical timing as a matched measurement. New A runs are used for the primary input comparison. Training and evaluation precision, optimization settings, budgets and checkpoint policy follow the shared pinned configurations.

Small correctness runs are disposable and never provide final checkpoints or choose B/C settings. Full runs use the three prescribed training seeds and exactly the prescribed update budget. Failures and undefined metrics are retained; no partial-seed mean substitutes for a complete three-seed result. The PIV-32 and image data/protocol blockers are enumerated separately in `rafm_input_study_protocol.md`.
